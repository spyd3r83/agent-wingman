# Asset provenance

`agent-wingman-logo.svg` is an original vector mark created specifically for Agent Wingman. It does not copy the OpenCode logo, a third-party icon set, or another product mark.

The asset contains only static SVG geometry, gradients, and accessibility metadata. It has no scripts, external resources, embedded raster data, fonts, tracking, or network references.

The logo is distributed under the repository's Apache-2.0 license. “Agent Wingman” is a project name; the Apache-2.0 license does not grant trademark rights.
